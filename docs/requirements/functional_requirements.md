# Overview
This section explains how to interpret the data shown in the Disaster Dashboard. It focuses on what each metric represents and how it should be understood when analyzing disaster response efforts.

## 1. Total Hours
Represents the total number of volunteer hours recorded for a disaster.
* Calculated from all volunteer submissions
* Limited to a maximum of 16 hours per entry

## 2. Total Value
Represents the estimated monetary value of contributions.
* Based on hourly rates assigned to the disaster
* Includes both standard and skilled labor

## 3. Skilled vs Standard Work
Volunteer work is divided into:
* **Standard Work** → Checked “no” skilled worker 
* **Skilled Work** → Requires admin confirmation

#### Important:
* Unsure skilled entries are treated as standard
* Only confirmed forms use the higher skilled rate

## 4. Donation Impact
Donations contribute to overall disaster impact in different ways:
* **Monetary donations** → Directly increase total value
* **Material and equipment donations** → May include hours or descriptions that contribute to reporting

## 5. Goal Progress
Each disaster includes a defined goal.
* The system tracks progress toward this goal
* Progress may be displayed as a percentage
* Helps measure overall response effectiveness

## 6. Flagged Data 
Flagged forms indicate data that may need review.
* These entries may still be included in totals
* Administrators should verify flagged data to ensure accuracy

## 7. Data Accuracy Considerations
* Analytics are based on submitted data
* Admin verification affects calculations (especially skilled labor)
* Soft-deleted records are excluded from active totals but retained for audit purposes
