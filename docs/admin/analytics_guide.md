# Overview
The Analytics Dashboard provides administrators with a summary of volunteer and donation activity for each disaster. It helps ERassist track overall impact, measure progress toward goals, and generate reports for decision-making and compliance.
Analytics are primarily viewed within the Disaster Dashboard, where data is specific to a selected disaster.

## 1. Key Metrics
### Total Volunteer Hours
The total number of hours submitted by all volunteers for a specific disaster.
* Calculated as the sum of all approved volunteer hours
* Maximum of 16 hours per day per volunteer is enforced

### Total Monetary Value
Represents the estimated dollar value of volunteer work.
This value is calculated using:
* Standard Hourly Rate
* Skilled Hourly Rate

### Standard vs Skilled Hours
Volunteer work is categorized into two types:
* **Standard Hours** → Regular volunteer work
* **Skilled Hours** → Work performed by verified skilled workers

#### Important:
* If a volunteer selects “unsure” on skilled worker section their hours are counted as standard
* Only confirmed skilled workers use the higher rate

### Goal Tracking
Each disaster includes a goal value, which represents the target impact.
This may represent:
* Total hours
* Total monetary value
The dashboard compares current totals against this goal to show progress.

## 2. Donation Metrics
### Total Donations
The total number of donation forms recorded for a disaster.

### Monetary Donations
The total dollar amount donated.
* Maximum single donation: $999,999.99

### Non-Monetary Contributions
Includes:
* Equipment
* Materials
* Other resources
Some of these may also include hours, which contribute to overall impact.

## 3. Flagged Data 
### What is Flagged Data?
Flagged forms are submissions that may require review due to:
* Invalid or inconsistent information
* Suspicious inputs
* Missing or unclear details

### Where to Find Flagged Data
* **General Dashboard** → Shows all flagged forms across disasters
* **Disaster Dashboard** → Shows flagged forms for that specific disaster

### How Flagged Data Affects Analytics
* Flagged entries may still be included in totals
* Admins should review flagged data to ensure accuracy

## 4. Data Filtering
Admins can filter analytics by:
* Disaster
* Date ranges (if applicable)
* Specific records (volunteers or donations)

This allows more precise reporting and analysis.

## 5. Data Accuracy Notes
* All analytics are based on submitted data
* Admin verification (especially for skilled workers) directly affects calculated values
* Soft-deleted records are not shown in normal analytics but remain stored for audit purposes

## 6. Using Analytics for Reporting
Analytics data can be used for:
* FEMA or compliance reporting
* Internal performance tracking
* Evaluating disaster response effectiveness
